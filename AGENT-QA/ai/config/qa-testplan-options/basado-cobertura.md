# Estrategia: Basado en Cobertura

## Resumen
Plan de pruebas orientado a maximizar cobertura funcional, lógica y técnica.

## Cuándo usar
Cuando el objetivo principal es garantizar trazabilidad y cobertura amplia de funcionalidades críticas.

## Reglas del plan de pruebas
1. Identificar funcionalidades críticas.
2. Asociar:
   - HU
   - reglas de negocio
   - escenarios
   - componentes
3. Medir cobertura:
   - funcional
   - requisitos
   - APIs
   - UI
4. Garantizar trazabilidad entre:
   - requisitos
   - casos
   - resultados
5. Priorizar componentes de alto riesgo.
6. Incluir métricas de cobertura esperadas.

## Tipos de prueba sugeridos
- Functional testing
- API testing
- Regression testing
- Boundary testing
- Integration testing

## Métricas sugeridas
- % cobertura funcional
- % cobertura requisitos
- % cobertura regresión

## Salida esperada
- Funcionalidades cubiertas
- Matriz de cobertura
- Riesgos no cubiertos
- Métricas esperadas
- Estrategia de validación
