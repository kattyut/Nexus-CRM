# Estrategia: Exploratorio

## Resumen
Testing dinámico basado en exploración funcional, experiencia del usuario y descubrimiento de defectos.

## Cuándo usar
Cuando:
- existen cambios frecuentes
- la documentación es limitada
- se busca descubrir comportamientos inesperados
- se valida experiencia de usuario

## Reglas del plan de pruebas
1. Definir objetivos de exploración.
2. Identificar áreas críticas y de riesgo.
3. Establecer timeboxes de exploración.
4. Documentar hallazgos relevantes.
5. Priorizar:
   - edge cases
   - flujos alternos
   - errores de validación
6. Promover pensamiento crítico y heurísticas QA.

## Tipos de prueba sugeridos
- Exploratory testing
- Usability testing
- Negative testing
- Edge case testing

## Técnicas sugeridas
- Session Based Testing
- Error Guessing
- Heurísticas UX
- Tours exploratorios

## Salida esperada
- Áreas exploradas
- Riesgos detectados
- Hallazgos
- Escenarios descubiertos
- Recomendaciones QA
