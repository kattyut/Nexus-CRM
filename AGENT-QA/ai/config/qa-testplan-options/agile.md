# Estrategia: Agile Testing

## Resumen
Plan de pruebas ligero, iterativo y adaptable alineado a metodologías ágiles como Scrum o Kanban.

## Cuándo usar
Cuando el proyecto trabaja por sprints, entregas incrementales y cambios frecuentes de requerimientos.

## Reglas del plan de pruebas
1. Mantener documentación liviana y enfocada en valor.
2. Definir alcance por sprint o incremento funcional.
3. Priorizar:
   - pruebas funcionales
   - smoke testing
   - regresión crítica
4. Incluir criterios de entrada y salida mínimos.
5. Alinear pruebas con Definition of Done (DoD).
6. Incluir riesgos funcionales prioritarios del sprint.
7. Promover colaboración entre QA, PO y desarrollo.

## Tipos de prueba sugeridos
- Smoke testing
- Functional testing
- Regression testing
- Exploratory testing
- UAT

## Salida esperada
- Objetivo del sprint
- Alcance funcional
- Estrategia de pruebas
- Riesgos
- Casos prioritarios
- Cobertura esperada
