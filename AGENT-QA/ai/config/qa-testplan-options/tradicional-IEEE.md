# Estrategia: Tradicional IEEE

## Resumen
Plan de pruebas formal basado en estándares IEEE 829 / ISO/IEC/IEEE 29119.

## Cuándo usar
Cuando el proyecto requiere:
- auditoría
- trazabilidad formal
- regulación
- documentación extensa
- control contractual

## Reglas del plan de pruebas
1. Definir alcance completo del testing.
2. Especificar:
   - objetivos
   - entregables
   - cronograma
   - recursos
3. Documentar:
   - ambiente
   - herramientas
   - dependencias
4. Incluir matriz de trazabilidad.
5. Definir criterios:
   - entrada
   - salida
   - suspensión
   - reanudación
6. Identificar riesgos y mitigaciones.
7. Mantener control documental y versionamiento.

## Tipos de prueba sugeridos
- Functional testing
- Integration testing
- System testing
- Regression testing
- Acceptance testing

## Salida esperada
- Introducción
- Alcance
- Estrategia
- Recursos
- Cronograma
- Riesgos
- Trazabilidad
- Criterios de aprobación
