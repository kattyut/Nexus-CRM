# Estrategia: Técnico funcional con NFR

## Resumen
Balancea necesidad funcional con detalles técnicos y no funcionales.

## Cuándo usar
Cuando además del valor funcional se necesita claridad técnica para implementación.

## Reglas de enriquecimiento
1. Separar claramente:
   - Necesidad de negocio
   - Reglas funcionales
   - Consideraciones técnicas
2. Incluir NFR mínimos:
   - Seguridad
   - Rendimiento
   - Trazabilidad/observabilidad
3. Declarar dependencias técnicas (APIs, colas, BD, terceros).
4. Definir criterios de aceptación funcionales y técnicos.

## Salida esperada
- Historia enriquecida
- Reglas funcionales
- Requisitos no funcionales
- Dependencias técnicas
- Criterios de aceptación
