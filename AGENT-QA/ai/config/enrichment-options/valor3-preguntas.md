# Estrategia: Valor por 3 preguntas

## Resumen
Enriquece enfocando la conversación en valor, forma de uso y validación.

## Cuándo usar
Cuando el pedido inicial está ambiguo y se necesita foco en valor.

## Reglas de enriquecimiento
1. Resolver explícitamente:
   - ¿Para qué se quiere esto?
   - ¿Cómo se quiere esto?
   - ¿Cómo se va a probar esto?
2. Convertir las respuestas en una historia de usuario consistente.
3. Definir mínimo 5 criterios de aceptación verificables.
4. Identificar riesgos de entendimiento y vacíos.

## Salida esperada
- Resumen de respuestas a las 3 preguntas
- Historia enriquecida
- Criterios de aceptación
- Riesgos y vacíos
