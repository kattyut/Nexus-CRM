# Estrategia: DoR lista para refinamiento

## Resumen
Deja la historia lista para sesión de refinamiento con Definition of Ready.

## Cuándo usar
Cuando no se indique estrategia o se necesite salida estándar por defecto.

## Reglas de enriquecimiento
1. Definir objetivo de negocio y valor esperado.
2. Delimitar alcance:
   - Incluye
   - No incluye
3. Especificar datos de entrada/salida relevantes.
4. Incluir mínimo 5 criterios de aceptación verificables.
5. Listar riesgos, dependencias y dudas pendientes.
6. Marcar supuestos cuando falte información.

## Salida esperada
- Historia enriquecida lista para DoR
- Alcance in/out
- Criterios de aceptación
- Riesgos, dependencias y preguntas abiertas
